# Prototypes

A collection of reusable business application prototypes addressing common operational challenges across industries as well as selected domain-specific scenarios.

The prototypes serve as starting points for evaluating ideas, discussing requirements and demonstrating potential solutions before investing into a full implementation.

## Cross-Industry Prototypes

| Prototype                                     | Description                                                                                            | Repository                                                               |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------ |
| **Service Desk Assistant**                    | Analyses incoming requests, suggests responses and prepares incidents for ticket systems such as OTRS. | [Repository](https://github.com/HeckelRobert/customer-support-assistant) |
| **Document Management Assistant** *(planned)* | Combines semantic search, question answering and revision-safe document management capabilities.       | Coming soon                                                              |
| **Excel Modernization** *(planned)*           | Demonstrates how business-critical Excel workflows can be transformed into maintainable applications.  | Coming soon                                                              |

## Characteristics

* Designed for rapid evaluation and adaptation
* Supports local and hosted Large Language Models
* Runs locally or can be integrated into existing infrastructures
* Focuses on solving business problems rather than showcasing technologies
* Can evolve into production-ready solutions
